# Regular Expressions (Regex)

This folder contains Python programs that demonstrate how to use **Regular Expressions (Regex)** for searching, matching, extracting, validating, and replacing text patterns.

## 📂 Files

### 1. `count_digits.py`
- Counts the number of digits present in a string using regex.

### 2. `extract_dates.py`
- Extracts dates from text using regular expression patterns.

### 3. `extract_hashtags.py`
- Finds and extracts hashtags from text.

### 4. `extract_numbers.py`
- Extracts numeric values from a string.

### 5. `find_uppercase.py`
- Finds uppercase letters or words using regex.

### 6. `find_words.py`
- Extracts words matching specific regex patterns.

### 7. `replace_spaces.py`
- Replaces spaces with another character or pattern using regex.

### 8. `validate_email.py`
- Validates email addresses using regular expressions.

## 📚 Concepts Practiced

- Regular Expressions (`re` module)
- Pattern Matching
- Character Classes
- Quantifiers
- Anchors (`^`, `$`)
- Word Boundaries (`\b`)
- `findall()`
- `search()`
- `match()`
- `sub()`

## 🚀 Learning Outcome

Through these implementations, I learned:
- Writing regex patterns for different text-processing tasks.
- Extracting useful information from strings.
- Validating input formats using regex.
- Replacing and manipulating text efficiently.
