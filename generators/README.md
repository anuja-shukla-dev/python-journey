# Python Generators

This folder contains beginner-friendly Python programs demonstrating the use of **generators** and the `yield` keyword for efficient sequence generation.

## 📚 Concepts Practiced

- Generators
- `yield` keyword
- Lazy Evaluation
- Iterators
- Memory Optimization
- Sequence Generation

## 🚀 Learning Outcome

Through these implementations, I learned:
- How generators differ from regular functions.
- How `yield` pauses and resumes function execution.
- Creating custom iterators using generators.
- Writing memory-efficient Python programs.
