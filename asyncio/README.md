# Asyncio Practice

This folder contains my practice programs for learning **Python `asyncio`** and asynchronous programming.

## Topics Covered

* Async functions (`async def`)
* `await`
* `asyncio.run()`
* `asyncio.sleep()`
* Running multiple coroutines with `asyncio.gather()`
* Returning values from async functions
* Concurrent task execution
* Countdown timer
* Download simulation
* Weather simulation
* Parallel factorial practice

## Learning Goals

* Understand asynchronous programming in Python
* Learn how the event loop works
* Practice running tasks concurrently
* Build a strong foundation for real-world asynchronous applications
