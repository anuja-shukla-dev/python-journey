# Function Caching (Dynamic Programming)

This folder contains Python implementations of classic Dynamic Programming problems solved using **function caching (memoization)**.


## 📚 Concepts Practiced

- Function Caching (`@cache` / `@lru_cache`)
- Memoization
- Dynamic Programming
- Recursion
- Overlapping Subproblems
- Optimal Substructure

## 🚀 Learning Outcome

Through these implementations, I learned:
- How memoization avoids repeated calculations.
- The difference between normal recursion and cached recursion.
- How function caching improves time complexity.
- Applying Dynamic Programming to recursive problems.
