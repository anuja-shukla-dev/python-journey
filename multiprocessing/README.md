# Multiprocessing in Python

This folder contains my practice programs for understanding **Multiprocessing in Python** and how Python executes multiple processes concurrently.

## Topics Covered

- **Creating Processes:** Creating and running processes using the `multiprocessing` module.
- **Process Identification:** Checking process IDs and understanding process execution.
- **Function Arguments:** Passing arguments to processes.
- **Inter-Process Communication:** Sharing data between processes using queues.

## Programs

| File | Description |
|---|---|
| `create_process.py` | Creating and executing processes using the multiprocessing module. |
| `check-process-id.py` | Checking process IDs to identify running processes. |
| `function_arguments.py` | Passing arguments to multiprocessing functions. |
| `share-data-using-queue.py` | Sharing data between processes using Queue. |

## Learning Objective

To understand how multiprocessing works, how independent processes execute, and how data can be exchanged between them.

## Module Used

```python
import multiprocessing
```
