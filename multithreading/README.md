# Multithreading in Python

This folder contains my practice programs for understanding **Multithreading in Python** and executing multiple threads within a single process.

## Topics Covered

- **Creating Threads:** Creating and running threads using the `threading` module.
- **Thread Execution:** Understanding how multiple threads execute concurrently.
- **Race Conditions:** Understanding race conditions that occur when multiple threads access shared resources.
- **Producer-Consumer Problem:** Implementing communication and synchronization between threads.
- **Thread Practice:** Applying multithreading concepts through practical programs.

## Programs

| File | Description |
|---|---|
| `practice.py` | General practice of multithreading concepts. |
| `running-threads.py` | Creating and running multiple threads. |
| `race-condition.py` | Demonstrating race conditions in multithreaded programs. |
| `producer-consumer.py` | Implementing the producer-consumer problem using threads. |

## Learning Objective

To understand thread creation, concurrent execution, synchronization challenges, and communication between threads.
